# AI 여행 추천 CLI

사용자가 **여행 날짜와 원하는 지역 또는 장소를 직접 입력**하면 Gemini API를 이용해 해당 지역의 여행 정보를 생성하고, Kakao Local API를 이용해 주변 맛집을 검색하여 최종 여행 리포트를 만드는 Python CLI 프로그램입니다.

동일한 날짜와 지역으로 다시 실행하면 기존에 저장된 JSON 데이터를 활용하는 **결과 캐싱 기능**을 지원합니다.

---

## 1. 프로젝트 소개

이 프로젝트는 Python CLI 환경에서 AI와 외부 API를 연동하여 사용자가 원하는 국내 지역의 여행 정보를 간편하게 확인할 수 있도록 구현한 프로그램입니다.

사용자는 명령어 옵션을 복잡하게 입력할 필요 없이 프로그램을 실행한 뒤 여행 날짜와 지역을 순서대로 입력할 수 있습니다.

예를 들어 다음과 같은 지역 입력이 가능합니다.

```text
강릉
강릉시
경주시
경주 황리단길
부산 해운대구
가평군
```

입력한 지역은 Gemini 여행 정보 생성과 Kakao 맛집 검색에 함께 사용됩니다.

---

## 2. 주요 기능

- 여행 날짜 대화형 입력
- 원하는 여행 지역 또는 장소 직접 입력
- 시, 군, 구, 동 및 관광지 등의 다양한 지역명 입력 지원
- Gemini API를 이용한 입력 지역 여행 정보 생성
- 해당 시기의 일반적인 계절 날씨 정보 생성
- 지역의 행사 및 축제 후보 생성
- 여행 추천 이유 생성
- Kakao Local API를 이용한 지역 맛집 검색
- 맛집 최대 5곳 검색
- 맛집 이름, 주소, 카테고리, URL, 좌표 제공
- 원본 결과 JSON 저장
- 최종 Markdown 여행 리포트 생성
- 날짜 + 지역 기준 결과 캐싱
- API 및 데이터 처리 과정의 예외 처리
- `.env`를 이용한 API 키 관리

## 9. Gemini API

Gemini API는 사용자가 입력한 날짜와 지역을 바탕으로 여행 정보를 생성합니다.

생성되는 주요 정보는 다음과 같습니다.

```json
{
  "recommended_city": "부산 해운대구",
  "weather": "해당 시기의 일반적인 날씨 정보",
  "events": [
    "행사 또는 축제 후보 1",
    "행사 또는 축제 후보 2"
  ],
  "reason": "해당 지역을 여행하기 좋은 이유"
}
```

`recommended_city`에는 사용자가 입력한 지역을 유지하도록 구성하여 Gemini가 임의로 다른 여행지로 변경하지 않도록 처리했습니다.

또한 날씨 정보는 실시간 날씨 조회 결과가 아니라 해당 날짜가 속한 시기의 일반적인 계절 특성을 기준으로 생성합니다.

---

## 10. Kakao Local API

Gemini 여행 정보 생성 후 사용자가 입력한 지역을 기준으로 Kakao Local API의 키워드 검색을 수행합니다.

예를 들어 사용자가 다음과 같이 입력했다면,

```text
부산 해운대구
```

검색에는 다음과 같은 형태의 키워드가 사용됩니다.

```text
부산 해운대구 맛집
```

검색 결과는 최대 5곳을 사용하며 다음 정보를 저장합니다.

- 맛집 이름
- 도로명 주소 또는 지번 주소
- 카테고리
- Kakao Map 장소 URL
- X 좌표
- Y 좌표

## 11. 결과 캐싱

외부 API의 불필요한 반복 호출을 줄이기 위해 간단한 결과 캐싱 기능을 구현했습니다.

캐시는 **여행 날짜 + 사용자가 입력한 지역**을 기준으로 구분합니다.

예를 들어 다음 조건으로 처음 실행하면,

```text
날짜: 2026-10-10
지역: 부산 해운대구
```

다음 JSON 파일이 생성됩니다.

```text
results/travel_2026-10-10_부산_해운대구.json
```

같은 날짜와 같은 지역을 다시 입력하면 프로그램은 해당 JSON 파일이 존재하는지 확인합니다.

파일이 존재하면 기존 여행 정보와 맛집 데이터를 읽어 사용하므로 여행 정보 생성과 맛집 검색을 위한 API 호출을 건너뜁니다.

실행 예:

```text
기존 결과 데이터를 발견했습니다.
API 호출을 건너뛰고 저장된 데이터를 사용합니다.
```

이를 통해 외부 API의 반복 호출을 줄여 실행 속도와 API 사용량을 절약할 수 있습니다.

## 12. 지역별 파일 관리

같은 날짜라도 서로 다른 지역의 결과가 덮어써지지 않도록 날짜와 지역을 파일명에 함께 사용합니다.

예를 들어:

```text
results/
├── travel_2026-09-21_경주_황리단길.json
├── travel_report_2026-09-21_경주_황리단길.md
├── travel_2026-10-10_부산_해운대구.json
└── travel_report_2026-10-10_부산_해운대구.md
```

지역명에 공백이 포함된 경우 파일명에서는 `_`로 변환합니다.

예:

```text
경주 황리단길
        ↓
경주_황리단길
```

Windows 파일명에서 사용할 수 없는 특수문자도 안전한 문자로 변환하도록 처리했습니다.

## 13. 원본 JSON 데이터

프로그램이 새 데이터를 생성하면 Gemini 여행 정보, Kakao 맛집 정보, 오류 정보를 하나의 JSON 파일에 저장합니다.

구조 예:

```json
{
  "date": "2026-10-10",
  "city": "부산 해운대구",
  "recommendation": {
    "recommended_city": "부산 해운대구",
    "weather": "10월 중순의 일반적인 날씨 정보",
    "events": [
      "행사 또는 축제 후보"
    ],
    "reason": "여행 추천 이유"
  },
  "restaurants": [
    {
      "name": "맛집 이름",
      "address": "맛집 주소",
      "category": "음식점 카테고리",
      "url": "Kakao Map 장소 URL",
      "x": 0.0,
      "y": 0.0
    }
  ],
  "errors": []
}
```

## 14. 최종 Markdown 리포트

원본 데이터를 이용하여 최종 여행 리포트를 Markdown 형식으로 생성합니다.

리포트에는 다음 항목이 포함됩니다.

```text
# 국내 여행 추천 리포트

## 1. 여행 지역
## 2. 날씨
## 3. 행사/축제
## 4. 추천 맛집
## 5. 1일 여행 일정
## 6. 오류 정보
```

최종 리포트 역시 날짜와 지역별로 구분하여 저장합니다.

```text
travel_report_2026-10-10_부산_해운대구.md
```

## 15. 날짜 검증

사용자가 입력한 날짜는 다음 형식을 사용해야 합니다.

```text
YYYY-MM-DD
```

정상 입력:

```text
2026-10-10
```

잘못된 입력 예:

```text
2026/10/10
10-10-2026
2026-13-40
```

잘못된 날짜가 입력되면 프로그램을 진행하지 않고 사용자에게 올바른 형식을 안내합니다.

본 프로젝트에서는 Python CLI 환경에서 Gemini API와 Kakao Local API를 연동하여 사용자가 원하는 국내 여행 지역의 정보와 맛집을 확인할 수 있는 프로그램을 구현했습니다.

사용자가 여행 날짜와 지역을 직접 입력할 수 있도록 하여 시, 군, 구, 동 또는 관광지 단위의 다양한 검색이 가능하도록 구성했습니다.

또한 날짜와 지역을 기준으로 원본 데이터를 캐싱하여 동일한 조건으로 다시 실행할 경우 기존 데이터를 재사용할 수 있도록 했습니다. 이를 통해 외부 API의 불필요한 반복 호출을 줄이고 실행 효율을 높였습니다.

최종적으로 여행 정보, 맛집 정보, 오류 정보를 JSON으로 저장하고 이를 기반으로 Markdown 여행 리포트를 생성하여 결과를 파일로 확인할 수 있도록 구성했습니다.
